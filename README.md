# feux-de-foret-nouvelle-aquitaine

Analyse du comportement de l'indice Météo des forêts (IFM) et des départs de feux
de forêt, pour aider le SDIS 33 (Gironde) à décider où concentrer ses moyens et à partir
de quel niveau de l'indice déclencher le dispositif renforcé pour l'été 2027.

**Région** : Nouvelle-Aquitaine (focus Gironde, 33)
**Commande** : SDIS 33, « Saison feux 2027 ». Réponse attendue le 11 décembre 2026.
**Cours** : Modélisation et pipeline de données, Présentation et communication technique, définition de KPIs, Dataviz décisionelle
